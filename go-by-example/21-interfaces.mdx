<GoExampleRow docs={"Here's a basic interface for geometric shapes."} language="go" code={"type geometry interface {\n    area() float64\n    perim() float64\n}"} />

<GoExampleRow docs={"For our example we'll implement this interface on `rect` and `circle` types."} language="go" code={"type rect struct {\n    width, height float64\n}\ntype circle struct {\n    radius float64\n}"} />

<GoExampleRow docs={"To implement an interface in Go, we just need to implement all the methods in the interface. Here we implement `geometry` on `rect`s."} language="go" code={"func (r rect) area() float64 {\n    return r.width * r.height\n}\nfunc (r rect) perim() float64 {\n    return 2*r.width + 2*r.height\n}"} />

<GoExampleRow docs={"The implementation for `circle`s."} language="go" code={"func (c circle) area() float64 {\n    return math.Pi * c.radius * c.radius\n}\nfunc (c circle) perim() float64 {\n    return 2 * math.Pi * c.radius\n}"} />

<GoExampleRow docs={"If a variable has an interface type, then we can call methods that are in the named interface. Here's a generic `measure` function taking advantage of this to work on any `geometry`."} language="go" code={"func measure(g geometry) {\n    fmt.Println(g)\n    fmt.Println(g.area())\n    fmt.Println(g.perim())\n}"} />

<GoExampleRow docs={"Sometimes it's useful to know the runtime type of an interface value. One option is using a *type assertion* as shown here; another is a [type `switch`](switch)."} language="go" code={"func detectCircle(g geometry) {\n    if c, ok := g.(circle); ok {\n        fmt.Println(\"circle with radius\", c.radius)\n    }\n}"} />
