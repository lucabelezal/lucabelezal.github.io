# Roadmap de Go e Backend

Se eu estivesse começando agora a transição de desenvolvimento mobile para backend, seguiria este caminho: aprender uma camada, construir algo pequeno e só avançar quando conseguisse explicar o que escrevi.

<GoRoadmap />

## Como estudar

- Siga as fases como uma ordem sugerida, não como uma lista para cumprir de uma vez.
- Pratique cada assunto com os exemplos da área de [Go by Example](/go).
- Use o projeto sugerido em cada fase como critério de entendimento.
- A partir da fase de APIs, evolua o mesmo serviço para perceber os problemas que aparecem com o tempo.
- Os posts entrarão aqui aos poucos, conforme cada assunto for estudado.

Não tente aprender tudo de backend antes de escrever uma API. O mapa mostra o território; a prática revela quais conceitos você realmente precisa aprofundar agora.
