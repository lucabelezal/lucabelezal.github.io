Caminho de arquivo parece simples até você precisar de portabilidade: no Linux é `dir/file`, no Windows `dir\file`, e no meio há `..`, barras duplas e `.` que precisam ser normalizados. O pacote **`path/filepath`** constrói e analisa caminhos do jeito certo do sistema — a regra de ouro: **nunca monte caminho concatenando strings**, use `filepath.Join`.

## Por que `Join` e nunca concatenação

`"dir1" + "/" + "dir2"` funciona no Linux e **quebra no Windows** (que usa `\`). `filepath.Join("dir1", "dir2")` usa o separador certo do sistema. Bônus: `Join` limpa barras duplas e resolve `..`/`.` — então `filepath.Join("a", "../b")` nem deveria ser usado assim (o `Rel`/absoluto cuidam de navegação), mas não deixa caminho "sujo" passar.

Consequência prática para todo o código de arquivos destas páginas: os exemplos usam `filepath.Join(os.TempDir(), "dat")` em vez de `"/tmp/dat"` — porque o diretório temporário varia por SO e usuário.

## Separar arquivo, diretório e extensão

- `filepath.Dir(p)` / `filepath.Base(p)` — diretório e arquivo.
- `filepath.Ext(p)` — extensão (`.json`), sem saber o resto.
- `strings.TrimSuffix(nome, ext)` — nome sem extensão.
- `filepath.Split(p)` — `(dir, file)` numa chamada.
- `filepath.Clean(p)` — normaliza sem `Join` (remove `..`, `.`, barras duplas).

## Em código real

- Montar caminhos de config/cache/download sempre com `Join`.
- `Rel` para gerar links relativos e mensagens amigáveis.
- `Ext`/`TrimSuffix` para trocar extensão (`config.json` → `config.yaml`).
- Cuidado com segurança: ao aceitar caminho de usuário, valide com `filepath.Clean` e confira que não escapa do diretório esperado (path traversal).

## Armadilhas comuns

- **Concatenar com `/`**: quebra no Windows. `filepath.Join`, sempre.
- **`filepath.Ext` pega a última extensão**: `a.tar.gz` → `.gz`. Para a "extensão composta", use `strings.TrimSuffix`/lógica própria.
- **`Rel` pode falhar**: se `base` e `target` estão em volumes/unidades diferentes (Windows), devolve erro — trate.
- **Assumir `/tmp`**: `os.TempDir()` é o certo; o caminho real varia (macOS → `$TMPDIR` longo).
- **`IsAbs` no Windows**: `C:\x` é absoluto, `/x` também; não assuma o separador.
