`git commit`, `go test`, `docker run`: ferramentas grandes são **vários programas num só**, cada um com suas próprias flags. Em Go, cada subcomando ganha um **`flag.FlagSet`** próprio — um parser de flags independente — e o `main` despacha pelo primeiro argumento. O `flag` global da página anterior vira um caso especial de um FlagSet chamado `CommandLine`.

## A anatomia: FlagSet + despacho

O esqueleto se repete para N subcomandos:

1. Um `flag.NewFlagSet(nome, flag.ExitOnError)` por subcomando, com as flags daquela ação.
2. Validar que veio subcomando (`len(os.Args) < 2` → uso + exit 1).
3. `switch os.Args[1]` para despachar.
4. `fs.Parse(os.Args[2:])` — o subcomando "consome" o primeiro arg, e o restante vai para as flags dele.

Cada `Parse` pode usar `ExitOnError` (sai sozinho, como o `flag` global) ou `ContinueOnError` (devolve o erro para você tratar — necessário quando o parsing é só uma parte da lógica).

## Em código real

Subcomandos são a forma de CLIs com ações (`install`/`remove`, `serve`/`migrate`). O `flag` cobre bem até uns 2-4 subcomandos; além disso (aliases, help aninhado, completions), a comunidade usa `cobra` — a base de `kubectl`, `gh` e `hugo`. O padrão de cima (um FlagSet por ação) é o que essas bibliotecas automatizam.

## Armadilhas comuns

- **Parsear o `os.Args` inteiro no subcomando**: o `Parse` recebe `os.Args[2:]` — sem isso, o nome do subcomando vira uma flag desconhecida.
- **Sem subcomando**: sem o guard `len(os.Args) < 2`, `os.Args[1]` panica. Sempre valide antes de indexar.
- **`ExitOnError` num servidor/biblioteca**: sair do processo por flag errada pode ser rude onde há mais contexto. Considere `ContinueOnError` e trate você mesmo.
- **Flags globais × de subcomando**: flags como `-v` (verbose) que valem para todo o programa precisam ser decididas antes do despacho — o modelo "global + por-subcomando" não vem pronto no `flag`.

## Pratique

1. **Reproduza**: rode os três casos da saída — `foo`, `bar` e `bar -enable` (erro).
2. **Modifique**: adicione um subcomando `baz` com uma flag `-modo` e o despacho correspondente no `switch`.
3. **Aplique**: crie uma mini-CLI `todo add "texto"` e `todo list` — `add` com flag `-prio`, `list` sem flags, compartilhando uma "store" simples (um arquivo JSON).
