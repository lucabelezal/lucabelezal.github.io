O timer dispara uma vez; o **ticker** dispara **repetidamente** a cada intervalo. O `time.NewTicker(d)` entrega um valor no channel `C` a cada `d` — o metrônomo do Go. Ele também tem `Stop()`: pare de ouvir quando não precisar mais.

<CodeExplanation
  title={"tickers.go"}
  code={`package main

import (
    "fmt"
    "time"
)

func main() {
    ticker := time.NewTicker(500 * time.Millisecond)
    done := make(chan bool)
    go func() {
        for {
            select {
            case <-done:
                return
            case t := <-ticker.C:
                fmt.Println("Tick at", t)
            }
        }
    }()
    time.Sleep(1600 * time.Millisecond)
    ticker.Stop()
    done <- true
    fmt.Println("Ticker stopped")
}`}

## Ticker × Timer

| | Timer | Ticker |
|---|---|---|
| Dispara | Uma vez | A cada intervalo |
| Channel `C` | 1 valor | N valores |
| Parar | `Stop()` antes de disparar | `Stop()` a qualquer momento |
| Uso | Timeout, agendar único | Heartbeat, polling periódico |

O ticker sem `Stop()` vaza: ele continua disparando (e a goroutine que o escuta, se existir) mesmo quando ninguém mais liga. **`Stop()` quando terminar** é a regra — e o channel `C` pode ter um tick pendente após o Stop, então o padrão com `done` (como aqui) garante a saída limpa da goroutine.

## Em código real

- **Heartbeat/health check**: enviar um sinal de "vivo" a cada N segundos.
- **Polling periódico**: checar uma fila, um status, métricas a cada intervalo.
- **Dashboards/relógios**: atualizar a cada segundo.
- Combinado com `select` e `done` (como aqui) ele vira a goroutine de fundo controlada — o padrão de ciclo de vida da página [Goroutines com Estado](stateful-goroutines).

## Armadilhas comuns

- **Ticker sem `Stop`**: goroutine/timer vazando. Pare sempre ao terminar.
- **Depender de ticks exatos**: o ticker entrega no ritmo do agendamento; se o consumidor demora, ticks podem ser **pulados** (o channel não acumula como fila ilimitada). Para agendar com precisão por contagem, acumule você mesmo.
- **Goroutine que nunca sai**: `Stop()` não mata a goroutine que faz `range ticker.C` — ela fica esperando. Use um canal `done` (como aqui) ou `range` com saída.
- **`time.Tick(d)` global**: devolve o channel sem `Stop` — vaza. Prefira `NewTicker` explícito.

## Pratique

1. **Reproduza**: rode `tickers.go` e conte os ticks até o Stop.
2. **Modifique**: mude o intervalo para 200ms e o sleep para 1s — quantos ticks agora? Depois remova o `Stop` e observe o comportamento no fim.
3. **Aplique**: escreva um ticker de heartbeat que a cada segundo loga \"vivo\" (página [Logging](logging)) e para ao receber um sinal `done` — o esqueleto de um health-check.
