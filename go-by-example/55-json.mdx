<GoExampleRow docs={"The JSON package can automatically encode your custom data types. <GoExampleRow docs={"You can use tags on struct field declarations to customize the encoded JSON key names. <GoExampleRow docs={"Now let's look at decoding JSON data into Go values. Here's an example for a generic data structure."} language="go" code={"    byt := []byte(`{\"num\":6.13,\"strs\":[\"a\",\"b\"]}`)"} />

<GoExampleRow docs={"We need to provide a variable where the JSON package can put the decoded data. This `map[string]any` will hold a map of strings to arbitrary data types."} language="go" code={"    var dat map[string]any"} />

<GoExampleRow docs={"Here's the actual decoding, and a check for associated errors. For the sake of brevity we ignore the errors in these examples; in real code, you should always check for errors and act upon them."} language="go" code={"    if err := json.Unmarshal(byt, &dat); err != nil {\n        panic(err)\n    }\n    fmt.Println(dat)"} />

<GoExampleRow docs={"In order to use the values in the decoded map, we'll need to convert them to their appropriate type. For example here we convert the value in `num` to the expected `float64` type."} language="go" code={"    num := dat[\"num\"].(float64)\n    fmt.Println(num)"} />

<GoExampleRow docs={"Accessing nested data requires a series of conversions."} language="go" code={"    strs := dat[\"strs\"].([]any)\n    str1 := strs[0].(string)\n    fmt.Println(str1)"} />

<GoExampleRow docs={"We can also decode JSON into custom data types. This has the advantages of adding additional type-safety to our programs and eliminating the need for type assertions when accessing the decoded data."} language="go" code={"    str := `{\"page\": 1, \"fruits\": [\"apple\", \"peach\"]}`\n    res := response2{}\n    _ = json.Unmarshal([]byte(str), &res)\n    fmt.Println(res)\n    fmt.Println(res.Fruits[0])"} />

<GoExampleRow docs={"In the examples above we always used bytes and strings as intermediates between the data and JSON representation on standard out. We can also stream JSON encodings directly to `io.Writer`s like `os.Stdout` or even HTTP response bodies."} language="go" code={"    d := map[string]int{\"apple\": 5, \"lettuce\": 7}\n    var buf bytes.Buffer\n    _ = json.MarshalWrite(&buf, d)\n    fmt.Println(buf.String())"} />

<GoExampleRow docs={"Streaming reads from `io.Reader`s like `os.Stdin` or HTTP request bodies is done with `json.UnmarshalRead`."} language="go" code={"    res1 := response2{}\n    _ = json.UnmarshalRead(strings.NewReader(str), &res1)\n    fmt.Println(res1)\n}"} />
