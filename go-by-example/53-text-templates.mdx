<GoExampleRow docs={"We can create a new template and parse its body from a string. Templates are a mix of static text and \"actions\" enclosed in `{{...}}` that are used to dynamically insert content."} language="go" code={"    t1 := template.New(\"t1\")\n    t1, err := t1.Parse(\"Value is {{.}}\\n\")\n    if err != nil {\n        panic(err)\n    }"} />

<GoExampleRow docs={"Alternatively, we can use the `template.Must` function to panic in case `Parse` returns an error. This is especially useful for templates initialized in the global scope."} language="go" code={"    t1 = template.Must(t1.Parse(\"Value: {{.}}\\n\"))"} />

<GoExampleRow docs={"By \"executing\" the template we generate its text with specific values for its actions. The `{{.}}` action is replaced by the value passed as a parameter to `Execute`."} language="go" code={"    t1.Execute(os.Stdout, \"some text\")\n    t1.Execute(os.Stdout, 5)\n    t1.Execute(os.Stdout, []string{\n        \"Go\",\n        \"Rust\",\n        \"C++\",\n        \"C#\",\n    })"} />

<GoExampleRow docs={"Helper function we'll use below."} language="go" code={"    Create := func(name, t string) *template.Template {\n        return template.Must(template.New(name).Parse(t))\n    }"} />

<GoExampleRow docs={"If the data is a struct we can use the `{{.FieldName}}` action to access its fields. The fields should be exported to be accessible when a template is executing."} language="go" code={"    t2 := Create(\"t2\", \"Name: {{.Name}}\\n\")"} />

<GoExampleRow docs={undefined} language="go" code={"    t2.Execute(os.Stdout, struct {\n        Name string\n    }{\"Jane Doe\"})"} />

<GoExampleRow docs={"The same applies to maps; with maps there is no restriction on the case of key names."} language="go" code={"    t2.Execute(os.Stdout, map[string]string{\n        \"Name\": \"Mickey Mouse\",\n    })"} />

<GoExampleRow docs={"if/else provide conditional execution for templates. A value is considered false if it's the default value of a type, such as 0, an empty string, nil pointer, etc. This sample demonstrates another feature of templates: using `-` in actions to trim whitespace."} language="go" code={"    t3 := Create(\"t3\",\n        \"{{if . -}} yes {{else -}} no {{end}}\\n\")\n    t3.Execute(os.Stdout, \"not empty\")\n    t3.Execute(os.Stdout, \"\")"} />

<GoExampleRow docs={"range blocks let us loop through slices, arrays, maps or channels. Inside the range block `{{.}}` is set to the current item of the iteration."} language="go" code={"    t4 := Create(\"t4\",\n        \"Range: {{range .}}{{.}} {{end}}\\n\")\n    t4.Execute(os.Stdout,\n        []string{\n            \"Go\",\n            \"Rust\",\n            \"C++\",\n            \"C#\",\n        })\n}"} />
