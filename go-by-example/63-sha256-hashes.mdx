Como garantir que um arquivo baixado não foi corrompido (ou adulterado)? Comparando sua **impressão digital**: o hash. `SHA-256` transforma qualquer dado num valor fixo de 32 bytes — mesma entrada, mesmo hash; mudou um bit, mudou tudo. O pacote `crypto/sha256` segue o padrão *hash.Hash* de Go: um writer em que você despeja os bytes e do qual tira o resumo no final.

## Por que o padrão hash.Hash (writer) existe

Em vez de `hash(dados)` de uma vez, o `hash.Hash` recebe bytes em **pedaços** (`Write`), acumula, e só no `Sum` produz o resumo. Isso permite hashear **arquivos grandes** e streams sem carregar tudo na memória — o mesmo desenho de `io.Writer` que você vê em todo o Go:

```go
f, _ := os.Open("arquivo.iso")
defer f.Close()
h := sha256.New()
io.Copy(h, f)   // hasheia o arquivo inteiro em streaming
fmt.Printf("%x\n", h.Sum(nil))
```

O atalho para dados pequenos é `sha256.Sum256([]byte(s))`, que devolve `[32]byte` pronto:

```go
sum := sha256.Sum256([]byte("dados"))
fmt.Printf("%x\n", sum)
```

## Para que serve (e para que NÃO serve)

**Serve**: verificar integridade de downloads e mensagens; comparar conteúdo sem guardar o original (armazena o hash, compara depois); detecção de mudança. O Git usa SHA-1 para identificar commits; a verificação de checksum de pacotes usa SHA-256.

**Não serve para senha**: SHA-256 é rápido demais — um atacante testa bilhões por segundo. Para senha use um *password hash* lento com salt: `bcrypt`, `argon2` (`golang.org/x/crypto/bcrypt`). E hash **não é assinatura**: qualquer um pode hashear; autenticar a origem exige HMAC ou criptografia de chave pública.

## Em código real

- Comparar dois hashes com `==` em `[32]byte` funciona (arrays são comparáveis). Para dados que são *segredo* (comparar um valor derivado de senha), use `crypto/subtle.ConstantTimeCompare` para evitar ataques de timing.
- SHA-256 também é a base de checksums em containers e de *Merkle trees* — mas para o dia a dia, o padrão acima resolve.

## Armadilhas comuns

- **Esquecer que SHA não é para senha**: rápido = fraco para senha. Bcrypt/argon2.
- **`Sum(nil)` reutilizável**: depois do `Sum`, o hasher ainda aceita `Write`. Se você quer um hash "fechado", crie um novo ou saiba que pode continuar.
- **Comparar hex string com `==`** é ok para integridade, mas para segredos use `subtle.ConstantTimeCompare`.
- **Hash de string vs bytes**: `sha256.Sum256("texto")` não compila — a função espera `[]byte`. Converta.

## Pratique

1. **Reproduza**: rode `sha256-hashes.go` e confira que o hash tem 64 hex. Rode de novo: idêntico.
2. **Modifique**: mude um caractere da string e veja o hash mudar por completo. Depois hasheie um arquivo com `io.Copy`.
3. **Aplique**: escreva `func hashArquivo(caminho string) (string, error)` que devolve o hash hex de um arquivo — e confira que dois arquivos iguais dão o mesmo hash.
