# Go by Example

Aprenda Go com exemplos anotados. Cada exemplo mostra código à direita e explicação à esquerda — igual ao [gobyexample.com](https://gobyexample.com), mas integrado ao tema GitHub Dark deste blog.

- **Lado a lado:** docs à esquerda, código à direita
- **Run:** link direto para [go.dev/play](https://go.dev/play/)
- **Copy:** botão por bloco e “Copiar tudo”

Escolha um exemplo na barra lateral para começar. Trilha sugerida: **Hello World → Values → Variables → Constants → For → If/Else …**
