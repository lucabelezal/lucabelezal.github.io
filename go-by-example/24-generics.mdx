Achar o índice de um elemento: uma função para `[]string`, outra para `[]int`, outra para `[]float64`? Sem **generics**, você duplicaria ou cairia em `any` + type assertion. Com generics, uma função serve para qualquer tipo que satisfaça a **restrição** — e o compilador verifica os tipos em tempo de compilação.

## Restrições: o "contrato" do tipo

`comparable` e `any` são as restrições embutidas; para ordenação existe `cmp.Ordered` (tipos com `<`). Restrições dizem **quais operações o corpo pode usar**: com `comparable`, você compara com `==`; com `cmp.Ordered`, compara com `<`. Se sua função precisa de um método específico, defina uma restrição com interface:

```go
type Stringer interface {
    String() string
}

func Descreve[T Stringer](v T) string {
    return v.String() // restrição garante o método
}
```

## Generics × interfaces: quando cada um

A distinção (que você já viu no guia de [Interfaces](interfaces)):

- **Interface** abstrai *comportamento* (métodos) de tipos **diferentes** — desacoplar, polimorfismo. `fmt.Stringer`, `io.Reader`.
- **Generics** abstrai *estrutura* (dados) mantendo o **tipo exato** — uma lista de `int` continua `[]int`, sem conversão.

Regra: se o código só chama métodos, interface basta; se ele precisa preservar/derivar o tipo (`List[int]`, `[]T`), generics. E um conselho de sênior: **generics também têm hora** — escreva a versão concreta primeiro e generalize quando a segunda duplicação aparecer (o mesmo "não extraia antes da hora" das interfaces).

## Em código real

- A stdlib já é genérica: `slices` (a função deste exemplo existe como `slices.Index`), `maps`, `cmp` — tudo que você usou nas páginas de [Slices](slices) e [Maps](maps).
- Containers tipados: filas, pilhas, caches `List[T]` — sem `any` + assertion.
- Helpers de coleção: filtrar/mapear mantendo o tipo.

## Armadilhas comuns

- **Restrição frouxa demais**: `[T any]` + `==` no corpo não compila (o `any` não garante `==`). Use `comparable` quando comparar.
- **`any` + type assertion por todo lado**: se você está convertendo dentro da função genérica, provavelmente a restrição está errada.
- **Receiver `*List` sem `[T]`**: erro — o parâmetro de tipo precisa estar no receiver.
- **`~[]E` esquecido**: sem o `~`, seu tipo `type MeuSlice []int` não satisfaz `S []E`. O `~` aceita "tipos baseados em".
- **Generalizar cedo demais**: generics custam legibilidade. Duas implementações concretas primeiro.

## Pratique

1. **Reproduza**: rode `generics.go`; depois chame `SlicesIndex` num `[]int` e num `[]float64` — sem mudar a função.
2. **Modifique**: escreva `func Mapa[T, U any](s []T, f func(T) U) []U` (o `map` funcional) e use com `func(n int) string`.
3. **Aplique**: crie `type Pilha[T any] struct{ ... }` com `Push`/`Pop` usando `[]T` — e reflita onde generics pouparam duplicação.
