<GoExampleRow docs={"As an example of a generic function, `SlicesIndex` takes a slice of any `comparable` type and an element of that type and returns the index of the first occurrence of v in s, or -1 if not present. The `comparable` constraint means that we can compare values of this type with the `==` and `!=` operators. For a more thorough explanation of this type signature, see [this blog post](https://go.dev/blog/deconstructing-type-parameters). Note that this function exists in the standard library as [slices.Index](https://pkg.go.dev/slices#Index)."} language="go" code={"func SlicesIndex[S ~[]E, E comparable](s S, v E) int {\n    for i := range s {\n        if v == s[i] {\n            return i\n        }\n    }\n    return -1\n}"} />

<GoExampleRow docs={"As an example of a generic type, `List` is a singly-linked list with values of any type."} language="go" code={"type List[T any] struct {\n    head, tail *element[T]\n}"} />

<GoExampleRow docs={undefined} language="go" code={"type element[T any] struct {\n    next *element[T]\n    val  T\n}"} />

<GoExampleRow docs={"We can define methods on generic types just like we do on regular types, but we have to keep the type parameters in place. The type is `List[T]`, not `List`."} language="go" code={"func (lst *List[T]) Push(v T) {\n    if lst.tail == nil {\n        lst.head = &element[T]{val: v}\n        lst.tail = lst.head\n    } else {\n        lst.tail.next = &element[T]{val: v}\n        lst.tail = lst.tail.next\n    }\n}"} />

<GoExampleRow docs={"AllElements returns all the List elements as a slice. In the next example we'll see a more idiomatic way of iterating over all elements of custom types."} language="go" code={"func (lst *List[T]) AllElements() []T {\n    var elems []T\n    for e := lst.head; e != nil; e = e.next {\n        elems = append(elems, e.val)\n    }\n    return elems\n}"} />
