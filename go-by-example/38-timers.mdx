Agendar algo para **daqui a X** é um timer. O `time.NewTimer(d)` cria um timer que entrega um valor no channel `C` quando o prazo chega — e, ao contrário do `time.Sleep`, ele pode ser **cancelado antes** de disparar.

<CodeExplanation
  title={"timers.go"}
  code={`package main

import (
    "fmt"
    "time"
)

func main() {
    timer1 := time.NewTimer(2 * time.Second)
    <-timer1.C
    fmt.Println("Timer 1 fired")
    timer2 := time.NewTimer(time.Second)
    go func() {
        <-timer2.C
        fmt.Println("Timer 2 fired")
    }()
    stop2 := timer2.Stop()
    if stop2 {
        fmt.Println("Timer 2 stopped")
    }
    time.Sleep(2 * time.Second)
}`}

## Timer × Sleep

| | `time.Sleep` | `time.NewTimer` |
|---|---|---|
| Espera | Simples, sem controle | Dá um channel `C` |
| Cancelar antes | Não dá | `timer.Stop()` |
| Usar em `select` | Não | `case <-timer.C:` (timeouts!) |

O timer é a versão *agendável* da espera: você pode esperar num `select`, cancelar, ou reutilizar. Para "dormir e pronto", o `Sleep` basta.

## Em código real

- **Timeout num select**: `time.After(d)` é açúcar para `NewTimer(d).C` — a página [Timeouts](timeouts) mostrou. Em laços, prefira `NewTimer` + `Stop` para não acumular.
- **Cancelar uma operação agendada**: `Stop()` antes do disparo evita que o trabalho aconteça.
- **`Reset`**: reiniciar um timer para um novo prazo (útil em retries com backoff).

Detalhe fino: depois que o timer dispara, se você não ler `C` e chamar `Stop()`, o `Stop` devolve `false` (já disparou). E o channel `C` entrega um valor — se você só quer o timer como timeout num select único, o valor não importa.

## Armadilhas comuns

- **Timer disparado e ninguém lê `C`**: não é leak grave, mas o valor fica lá; num loop, drene ou use `Stop`.
- **`Stop` devolve `false` e você assume que disparou**: `false` também acontece se o valor já foi entregue. Interprete com cuidado.
- **`time.After` em laço**: cria um timer por iteração — use `NewTimer` + `Reset` quando o laço é longo (relembre a página [Timeouts](timeouts)).
- **Usar timer onde `context.WithTimeout` é melhor**: para operações que têm contexto, o timer manual e o `select` funcionam, mas o `ctx` propaga o prazo pelas camadas (página [Context](context)).

## Pratique

1. **Reproduza**: rode `timers.go` e confirme que \"Timer 2 fired\" nunca aparece.
2. **Modifique**: remova o `Stop()` — agora \"Timer 2 fired\" aparece antes do fim (depois de 1s). Depois use `timer2.Reset(1 * time.Second)` e observe.
3. **Aplique**: reimplemente o timeout da página [Timeouts](timeouts) com `NewTimer` + `Stop` explícito num laço de 3 tentativas.
