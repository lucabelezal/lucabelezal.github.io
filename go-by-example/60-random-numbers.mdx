Sorteio, ID de sessão, ruído num teste, amostragem — tudo precisa de **números aleatórios**. Desde o Go 1.22 o pacote é `math/rand/v2`: as funções globais são **auto-seeded** (sem a velha cerimônia de semear com o tempo) e há geradores com seed explícito para quando você quer **reproduzibilidade** (testes!). E uma linha vermelha: aleatório para **segurança** usa outro pacote, `crypto/rand`.

## Global auto-seeded × gerador com seed

- **Global** (`rand.IntN`, `rand.Float64`): para a maioria dos casos. No v2 não precisa semear — o runtime cuida. Seguro em goroutines.
- **Gerador próprio** (`rand.New(rand.NewPCG(...))`): quando a sequência precisa ser **reproduzível** (testes, simulações, demos) ou isolada (duas partes do código sem interferir no estado uma da outra). Mesma seed → mesmos números, sempre.

Regra: produção usa o global; **teste usa seed fixa** — aí o teste falha de forma determinística, não "de vez em quando".

## A linha vermelha: segurança não é aqui

`math/rand` é **previsível** — serve para estatística, jogos, amostragem. **Nunca** use para senha, token, chave, nonce. Para isso existe `crypto/rand`, que tira entropia do sistema:

```go
import "crypto/rand"

b := make([]byte, 16)
rand.Read(b) // imprevisível, para tokens/chaves
```

(página futura explora criptografia; a regra é: dado que protege algo → `crypto/rand`.)

## Armadilhas comuns

- **Semear o global à mão no v1**: no `math/rand` antigo era `rand.Seed(time.Now().UnixNano())`. No v2 isso **não existe mais** — o global já é auto-seeded. Se viu código com `rand.Seed`, está no v1.
- **Usar `math/rand` para token/segurança**: previsível = quebrável. `crypto/rand`, sempre.
- **Confiar que `IntN` inclui o limite**: `rand.IntN(100)` vai de 0 a 99, nunca 100.
- **Gerador global alterado por teste**: se um teste semeia o global, afeta a sequência de todo o pacote. Use gerador próprio com seed local no teste.

## Pratique

1. **Reproduza**: rode `random-numbers.go` duas vezes — as duas primeiras linhas mudam, as duas últimas não.
2. **Modifique**: gere um inteiro em `[10, 20)` e um float em `[0, 1)` formatado com 2 casas.
3. **Aplique**: escreva um teste que usa `rand.New(rand.NewPCG(1,2))` para sortear uma ordem — rode várias vezes e veja a sequência se repetir.
