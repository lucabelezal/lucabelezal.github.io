Argumentos posicionais não têm nome nem valor padrão. Para opções como `-port=8080` ou `-verbose`, Go tem o pacote **`flag`** da stdlib: você declara a flag com nome, default e descrição; o `flag.Parse()` preenche; e o **help** (`-h`) sai de graça. Simples o bastante para ferramentas — e é o que o próprio `go` usa.

## A regra que pega todo mundo: flags antes dos posicionais

O parsing do `flag` para no **primeiro argumento posicional** — tudo depois dele é `flag.Args()`, mesmo que pareça flag:

```
$ ./command-line-flags -word=opt a1 a2 a3 -numb=7
word: opt
numb: 42        ← -numb=7 foi para o tail, não virou flag
tail: [a1 a2 a3 -numb=7]
```

Flags primeiro, posicionais depois. É o comportamento do pacote; documente no help.

## Help e erro, de graça

`-h`/`--help` gera o help automaticamente a partir das descrições:

```
$ ./command-line-flags -h
Usage of ./command-line-flags:
  -fork
    	a bool
  -numb int
    	an int (default 42)
  -svar string
    	a string var (default "bar")
  -word string
    	a string (default "foo")
```

E flag desconhecida é erro + help + exit:

```
$ ./command-line-flags -wat
flag provided but not defined: -wat
Usage of ./command-line-flags:
...
```

## Em código real

O pacote `flag` é o padrão para **ferramentas** (`go run`, `go test`, linters usam o próprio ou wrappers). Limites dele aparecem quando você quer flags de subcomando (próxima página), aliases (`-v` e `-verbose`), ou help customizado — aí o ecossistema tem `cobra`/`pflag` para CLIs maiores. Comece com `flag`; ele cobre a maioria.

## Armadilhas comuns

- **Esquecer `flag.Parse()`**: declaração sem parse = defaults eternos. A linha `flag.Parse()` é obrigatória.
- **Dereferenciar o ponteiro errado**: `flag.String` devolve ponteiro — usar `wordPtr` sem `*` imprime o endereço. `flag.StringVar` evita o ponteiro quando você prefere variável.
- **Flags depois de posicional**: viram `flag.Args()`. Reordene ou documente.
- **`-h` sair do programa**: o `flag` trata `-h` como pedido de help e termina com exit 0 — não é erro.
- **Comparar com `go run`**: `go run main.go -flag=x` funciona, mas `go run -flag=x main.go` não — o `-flag` iria para o `go run`. Compile ou use `--`.

## Pratique

1. **Reproduza**: rode o binário com todas as flags, com só o default, e com `-h` — compare as saídas.
2. **Modifique**: declare uma flag `-nome` com default `"mundo"` e imprima `Olá, <nome>!`; teste a regra de posicional com `./prog -nome=Go arquivo.txt -nome=x`.
3. **Aplique**: escreva um `saudacao` com flags `-nome`, `-gritar` (bool) e um argumento posicional de destinatário — e monte a mensagem condicionalmente.

## Próximo passo
