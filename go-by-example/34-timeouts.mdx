<GoExampleRow docs={"For our example, suppose we're executing an external call that returns its result on a channel `c1` after 2s. Note that the channel is buffered, so the send in the goroutine is nonblocking. This is a common pattern to prevent goroutine leaks in case the channel is never read."} language="go" code={"    c1 := make(chan string, 1)\n    go func() {\n        time.Sleep(2 * time.Second)\n        c1 <- \"result 1\"\n    }()"} />

<GoExampleRow docs={"Here's the `select` implementing a timeout. `res := <-c1` awaits the result and `<-time.After` awaits a value to be sent after the timeout of 1s. Since `select` proceeds with the first receive that's ready, we'll take the timeout case if the operation takes more than the allowed 1s."} language="go" code={"    select {\n    case res := <-c1:\n        fmt.Println(res)\n    case <-time.After(1 * time.Second):\n        fmt.Println(\"timeout 1\")\n    }"} />

<GoExampleRow docs={"If we allow a longer timeout of 3s, then the receive from `c2` will succeed and we'll print the result."} language="go" code={"    c2 := make(chan string, 1)\n    go func() {\n        time.Sleep(2 * time.Second)\n        c2 <- \"result 2\"\n    }()\n    select {\n    case res := <-c2:\n        fmt.Println(res)\n    case <-time.After(3 * time.Second):\n        fmt.Println(\"timeout 2\")\n    }\n}"} />
