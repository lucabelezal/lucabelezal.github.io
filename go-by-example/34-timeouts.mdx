import (
    "fmt"
    "time"
)

func main() {
    c1 := make(chan string, 1)
    go func() {
        time.Sleep(2 * time.Second)
        c1 <- "result 1"
    }()
    select {
    case res := <-c1:
        fmt.Println(res)
    case <-time.After(1 * time.Second):
        fmt.Println("timeout 1")
    }
    c2 := make(chan string, 1)
    go func() {
        time.Sleep(2 * time.Second)
        c2 <- "result 2"
    }()
    select {
    case res := <-c2:
        fmt.Println(res)
    case <-time.After(3 * time.Second):
        fmt.Println("timeout 2")
    }
}`}
  sections={[
    {text: "Suponha uma chamada externa que retorna o resultado em `c1` após 2s. O channel é bufferizado, então o send na goroutine não bloqueia. Padrão comum para evitar vazamento de goroutine caso o channel nunca seja lido."},
    {text: "Aqui o `select` implementa timeout. `res := <-c1` aguarda o resultado e `<-time.After` aguarda após 1s. Como `select` segue o primeiro pronto, pegamos o caso de timeout se a operação demorar mais que 1s."},
    {text: "Se permitirmos timeout maior de 3s, o receive de `c2` terá sucesso e imprimimos o resultado."},
