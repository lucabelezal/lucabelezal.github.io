<GoExampleRow docs={"We implement a comparison function for string lengths. `cmp.Compare` is helpful for this."} language="go" code={"    lenCmp := func(a, b string) int {\n        return cmp.Compare(len(a), len(b))\n    }"} />

<GoExampleRow docs={"Now we can call `slices.SortFunc` with this custom comparison function to sort `fruits` by name length."} language="go" code={"    slices.SortFunc(fruits, lenCmp)\n    fmt.Println(fruits)"} />

<GoExampleRow docs={"We can use the same technique to sort a slice of values that aren't built-in types."} language="go" code={"    type Person struct {\n        name string\n        age  int\n    }"} />

<GoExampleRow docs={undefined} language="go" code={"    people := []Person{\n        Person{name: \"Jax\", age: 37},\n        Person{name: \"TJ\", age: 25},\n        Person{name: \"Alex\", age: 72},\n    }"} />

<GoExampleRow docs={"Sort `people` by age using `slices.SortFunc`.  Note: if the `Person` struct is large, you may want the slice to contain `*Person` instead and adjust the sorting function accordingly. If in doubt, [benchmark](testing-and-benchmarking)!"} language="go" code={"    slices.SortFunc(people,\n        func(a, b Person) int {\n            return cmp.Compare(a.age, b.age)\n        })\n    fmt.Println(people)\n}"} />
