Imprimir um valor "de qualquer jeito" é fácil; imprimir **do jeito certo** é formatação. O `fmt` oferece *verbs* — `%v`, `%d`, `%s`, `%f`... — que controlam como cada valor vira texto. Eles aparecem em `Printf` (stdout), `Sprintf` (retorna string) e `Fprintf` (qualquer `io.Writer`), e valem para logs, mensagens de erro e relatórios.

## Os verbs que você vai usar 90% do tempo

| Verb | Para quê | Exemplo |
|---|---|---|
| `%v` | Valor no formato padrão (o "não sei qual é, imprime" da formatação) | `{1 2}` |
| `%+v` | Struct com nome dos campos (debug) | `{x:1 y:2}` |
| `%#v` | Sintaxe Go do valor (debug profundo) | `main.point{x:1, y:2}` |
| `%T` | O tipo | `main.point` |
| `%d` | Inteiro decimal | `123` |
| `%s` / `%q` | String crua / com aspas | `"string"` |
| `%f` / `%.2f` | Float / com 2 casas | `78.90` |
| `%t` | Booleano | `true` |

Dois bônus importantes:

- **`%v` respeita `fmt.Stringer`**: se o tipo tem `String() string`, `%v` o chama. É assim que `fmt.Println` "sabe" imprimir bem um tipo — você implementa `String()` (visto em [Interfaces](interfaces)) e todo `fmt` passa a usar.
- **`%w` não é para `Printf`**: é o verb de *wrap* do `fmt.Errorf`, da página de [Erros](errors) — ele preserva a cadeia de erros. `%v` com um erro imprime só a mensagem.

## Onde cada variante vive

- `fmt.Printf` — imprime em `os.Stdout`.
- `fmt.Sprintf` — **retorna** a string: montar mensagens, `errors.New(fmt.Sprintf(...))`, logs.
- `fmt.Fprintf(w, ...)` — escreve em qualquer `io.Writer`: arquivo, `os.Stderr`, um `http.ResponseWriter` (aparece em [Servidor HTTP](http-server)).

Em logs de produção você normalmente não formata na mão — usa um logger estruturado (página de [Logging](logging)). A formatação manual brilha para output de usuário, relatórios e debugging.

## Armadilhas comuns

- **Verb errado**: `%d` com float imprime `%!d(float64=1.2)` — o `fmt` sinaliza o erro no próprio texto. Use o verb certo ou `%v`.
- **Esquecer o `\n`**: `Printf` **não** adiciona quebra de linha (diferente de `Println`). Saídas grudadas são o sintoma clássico.
- **`%v` para debug de struct**: esconde os nomes dos campos. Para inspecionar estado, use `%+v`.
- **Precisão em `%f` vs `%v` de float**: `%v` imprime `78.9`; `%f` imprime `78.900000` (6 casas padrão). Escolha de propósito.
- **Achar que largura trunca**: `%6d` com um número maior que 6 não corta — só usa mais espaço. Largura é mínimo, não máximo.

## Pratique

1. **Reproduza**: rode `string-formatting.go` e compare `str1` com `str2` — explique as aspas extra.
2. **Modifique**: formate `point{1,2}` com `%+v` e `%#v` e monte uma tabela alinhada de `{nome, idade}` com `%6s`/`%-6s`.
3. **Aplique**: crie um tipo `type conta struct{ titular string; saldo float64 }` com `String() string` (use `%s`/`%.2f`) e veja `fmt.Println(conta)` mudar — depois use `Sprintf` para montar uma linha de extrato.
