Ler arquivos em Go é ler **streams de bytes** com o pacote `os` + `io` + `bufio`. Tem três níveis: ler tudo de uma vez (`os.ReadFile`), abrir e ler com controle (`os.Open` + `Read`/`Seek`), e ler bufferizado por linhas (`bufio`). Quase toda chamada devolve erro — o padrão `if err != nil` aparece em cada passo.

## Três níveis de leitura

| Nível | Quando | Função |
|---|---|---|
| Tudo de uma vez | Config, arquivos pequenos que cabem na memória | `os.ReadFile` |
| Streaming com controle | Processar pedaço, pular posições | `os.Open` + `Read`/`Seek` |
| Por linha / token | Texto linha a linha, CSVs | `bufio.Scanner` / `bufio.Reader` |

Escolha pelo tamanho: `ReadFile` carrega tudo; arquivos grandes (logs, downloads) pedem streaming. A leitura **por linha** com `bufio.Scanner` é tão comum que ganha página própria em [Filtros de Linha](line-filters).

## O contrato do `io.Reader`

`Read` não promete encher o buffer — pode devolver menos bytes (ou `io.EOF` no fim). Por isso todo loop de leitura usa o `n` retornado. As funções do `io` (`ReadAll`, `ReadAtLeast`, `Copy`) encapsulam esse contrato para você não repetir o laço à mão. É o mesmo `io.Reader` que alimenta hashes, JSON decoders e `http.Response.Body`.

## Em código real

- `os.ReadFile` para config (ou o embed da página de [Diretiva Embed](embed-directive) para arquivos que viajam no binário).
- `bufio.Scanner` para logs e arquivos texto.
- `os.Open` + `io.Copy` quando você só repassa o conteúdo (ex.: servir um arquivo estático).

## Armadilhas comuns

- **Usar `b1` inteiro em vez de `b1[:n1]`**: o resto do buffer tem lixo de leituras anteriores. Sempre corte pelo `n`.
- **Esquecer o `Close`**: em código longo ou laços, arquivo aberto vaza descritor. `defer f.Close()` logo após abrir.
- **`ReadFile` em arquivo gigante**: carrega tudo na RAM. Para arquivos grandes, stream.
- **Ignorar `io.EOF`**: no fim do arquivo, `Read` devolve `(0, io.EOF)`. Trate como fim normal, não como erro.
- **Caminho com `TempDir`**: em macOS, `os.TempDir()` é um diretório longo do `$TMPDIR`, não `/tmp` literal. Use `filepath.Join(os.TempDir(), ...)`, nunca concatene barra na mão (página [Caminhos de Arquivos](file-paths)).

## Pratique

1. **Reproduza**: crie `/tmp`-equivalente com `hello\ngo\n`, rode `reading-files.go` e relacione cada linha da saída ao `Seek` que a produziu.
2. **Modifique**: leia o arquivo de trás para frente usando `Seek(-1, io.SeekEnd)` e lendo byte a byte até o início.
3. **Aplique**: escreva `func primeirasLinhas(caminho string, n int) ([]string, error)` com `bufio.Scanner` — e trate o erro de abertura.
