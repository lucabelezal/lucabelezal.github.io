Ordenar é uma das operações mais comuns — e uma das que você **não** deve implementar na mão. O pacote `slices` (Go 1.21+) traz o `slices.Sort`, **genérico** (página [Generics](generics)): funciona para qualquer tipo ordenável (`int`, `float64`, `string`...), ordena o slice no lugar e ainda dá o `IsSorted` para checar.

## O pacote slices: ordenação e além

`slices.Sort` é só a ponta. O mesmo pacote traz o resto do kit:

| Função | O que faz |
|---|---|
| `slices.Sort(s)` | Ordena no lugar |
| `slices.SortFunc(s, cmp)` | Ordena com critério próprio (próxima página) |
| `slices.SortStableFunc` | Ordenação **estável** (mantém ordem de iguais) |
| `slices.IsSorted(s)` / `IsSortedFunc` | Já está ordenado? |
| `slices.Reverse(s)` | Inverte (para ordem decrescente: `Sort` + `Reverse`) |
| `slices.BinarySearch(s, v)` | Busca binária num slice ordenado |

Antes do `slices`, a ordenação vivia em `sort` (`sort.Slice`, `sort.Strings`); o `slices` é o caminho moderno e genérico.

## Notas de comportamento

- **No lugar**: `slices.Sort` modifica o slice que você passa (não devolve um novo). Se precisa preservar o original, `slices.Clone` antes.
- **String é lexicográfica por byte**: `"b"` vem antes de `"ba"`, e maiúsculas antes de minúsculas (`"B" < "a"`). Para ordem que ignora caixa ou acento, você precisa do critério próprio — próxima página.
- **`slices.Sort` é estável**: elementos iguais mantêm a ordem relativa.

## Em código real

Ordenar para exibir (listas de nomes, rankings), para preparar busca binária (`BinarySearch` exige ordem), para testes determinísticos (iterar um map numa ordem fixa — relembre que a iteração de [Maps](maps) é aleatória):

```go
chaves := maps.Keys(meuMap)   // página [Maps](maps)
slices.Sort(chaves)           // ordem determinística
for _, k := range chaves { ... }
```

## Armadilhas comuns

- **Esperar um slice novo**: `Sort` modifica o original. Não usar o retorno (não tem) — e clonar antes se a ordem importa.
- **Achar que `Sort` aceita qualquer tipo**: só tipos `cmp.Ordered` (números e strings). Struct seu? É `SortFunc` (próxima página).
- **String por "ordem natural"**: `"item10" < "item9"` lexicograficamente (o `"1"` < `"9"`). Ordenação natural de números em texto pede critério próprio.
- **Busca binária num slice não ordenado**: `BinarySearch` só é correta em slice ordenado.

## Pratique

1. **Reproduza**: rode `sorting.go`; depois ordene um `[]float64` e um `[]byte` — uma função só.
2. **Modifique**: produza ordem **decrescente** com `Sort` + `slices.Reverse`; depois verifique com `IsSorted` (false!) e `IsSortedFunc` se quiser.
3. **Aplique**: ordene as chaves de um `map[string]int` (frequências de palavras) e imprima em ordem alfabética determinística.
