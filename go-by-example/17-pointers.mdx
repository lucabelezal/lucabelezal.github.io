<GoExampleRow docs={"We'll show how pointers work in contrast to values with 2 functions: `zeroval` and `zeroptr`. `zeroval` has an `int` parameter, so arguments will be passed to it by value. `zeroval` will get a copy of `ival` distinct from the one in the calling function."} language="go" code={"func zeroval(ival int) {\n    ival = 0\n}"} />

<GoExampleRow docs={"`zeroptr` in contrast has an `*int` parameter, meaning that it takes an `int` pointer. The `*iptr` code in the function body then _dereferences_ the pointer from its memory address to the current value at that address. Assigning a value to a dereferenced pointer changes the value at the referenced address."} language="go" code={"func zeroptr(iptr *int) {\n    *iptr = 0\n}"} />

<GoExampleRow docs={undefined} language="go" code={"func main() {\n    i := 1\n    fmt.Println(\"initial:\", i)"} />

<GoExampleRow docs={undefined} language="go" code={"    zeroval(i)\n    fmt.Println(\"zeroval:\", i)"} />

<GoExampleRow docs={"The `&i` syntax gives the memory address of `i`, i.e. a pointer to `i`."} language="go" code={"    zeroptr(&i)\n    fmt.Println(\"zeroptr:\", i)"} />

<GoExampleRow docs={"Pointers can be printed too."} language="go" code={"    fmt.Println(\"pointer:\", &i)"} />

<GoExampleRow docs={"A new pointer to a value can be created with the builtin function `new`."} language="go" code={"    p := new(42)\n    fmt.Println(\"value at *p:\", *p)\n    zeroptr(p)\n    fmt.Println(\"value at *p:\", *p)\n}"} />
