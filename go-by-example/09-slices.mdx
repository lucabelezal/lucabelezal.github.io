<GoExampleRow docs={"Unlike arrays, slices are typed only by the elements they contain (not the number of elements). An uninitialized slice equals to nil and has length 0."} language="go" code={"    var s []string\n    fmt.Println(\"uninit:\", s, s == nil, len(s) == 0)"} />

<GoExampleRow docs={"To create a slice with non-zero length, use the builtin `make`. Here we make a slice of `string`s of length `3` (initially zero-valued). By default a new slice's capacity is equal to its length; if we know the slice is going to grow ahead of time, it's possible to pass a capacity explicitly as an additional parameter to `make`."} language="go" code={"    s = make([]string, 3)\n    fmt.Println(\"emp:\", s, \"len:\", len(s), \"cap:\", cap(s))"} />

<GoExampleRow docs={"We can set and get just like with arrays."} language="go" code={"    s[0] = \"a\"\n    s[1] = \"b\"\n    s[2] = \"c\"\n    fmt.Println(\"set:\", s)\n    fmt.Println(\"get:\", s[2])"} />

<GoExampleRow docs={"`len` returns the length of the slice as expected."} language="go" code={"    fmt.Println(\"len:\", len(s))"} />

<GoExampleRow docs={"In addition to these basic operations, slices support several more that make them richer than arrays. One is the builtin `append`, which returns a slice containing one or more new values. Note that we need to accept a return value from `append` as we may get a new slice value."} language="go" code={"    s = append(s, \"d\")\n    s = append(s, \"e\", \"f\")\n    fmt.Println(\"apd:\", s)"} />

<GoExampleRow docs={"Slices can also be `copy`'d. Here we create an empty slice `c` of the same length as `s` and copy into `c` from `s`."} language="go" code={"    c := make([]string, len(s))\n    copy(c, s)\n    fmt.Println(\"cpy:\", c)"} />

<GoExampleRow docs={"Slices support a \"slice\" operator with the syntax `slice[low:high]`. For example, this gets a slice of the elements `s[2]`, `s[3]`, and `s[4]`."} language="go" code={"    l := s[2:5]\n    fmt.Println(\"sl1:\", l)"} />

<GoExampleRow docs={"This slices up to (but excluding) `s[5]`."} language="go" code={"    l = s[:5]\n    fmt.Println(\"sl2:\", l)"} />

<GoExampleRow docs={"And this slices up from (and including) `s[2]`."} language="go" code={"    l = s[2:]\n    fmt.Println(\"sl3:\", l)"} />

<GoExampleRow docs={"We can declare and initialize a variable for slice in a single line as well."} language="go" code={"    t := []string{\"g\", \"h\", \"i\"}\n    fmt.Println(\"dcl:\", t)"} />

<GoExampleRow docs={"The `slices` package contains a number of useful utility functions for slices."} language="go" code={"    t2 := []string{\"g\", \"h\", \"i\"}\n    if slices.Equal(t, t2) {\n        fmt.Println(\"t == t2\")\n    }"} />

<GoExampleRow docs={"Slices can be composed into multi-dimensional data structures. The length of the inner slices can vary, unlike with multi-dimensional arrays."} language="go" code={"    twoD := make([][]int, 3)\n    for i := range 3 {\n        innerLen := i + 1\n        twoD[i] = make([]int, innerLen)\n        for j := range innerLen {\n            twoD[i][j] = i + j\n        }\n    }\n    fmt.Println(\"2d: \", twoD)\n}"} />
