Criar, listar e percorrer **diretórios** é a base de qualquer ferramenta que anda pelo sistema de arquivos. O `os` traz `Mkdir`/`MkdirAll` para criar (com `mkdir -p` incluído), `ReadDir` para listar, e o `filepath.WalkDir` percorre uma árvore inteira chamando um *callback* para cada arquivo — mais um lugar onde funções como valores aparecem.

## Criar × listar × percorrer

| Operação | Função | Equivalente |
|---|---|---|
| Criar um diretório | `os.Mkdir(dir, perm)` | `mkdir dir` |
| Criar hierarquia | `os.MkdirAll(dir, perm)` | `mkdir -p dir` |
| Listar conteúdo | `os.ReadDir(dir)` | `ls dir` |
| Percorrer recursivo | `filepath.WalkDir(root, fn)` | `find dir` |
| Remover árvore | `os.RemoveAll(dir)` | `rm -rf dir` |

`WalkDir` é a joia: em vez de você escrever a recursão (página [Recursão](recursion)), ela caminha sozinha e chama seu callback — com a ordem garantida (pais antes dos filhos) e erro propagado pelo retorno do callback.

## Em código real

- **Criar estrutura no startup**: `os.MkdirAll(caminhoConfig, 0o755)` — "garanta que existe".
- **Varrer arquivos**: procurar por extensão, listar para backup, calcular tamanho de uma árvore — tudo com `WalkDir` + `d.IsDir()`/`d.Info()`.
- **Limpeza**: `defer os.RemoveAll` em testes e em diretórios temporários (a página de [Arquivos Temporários](temporary-files-and-directories) usa exatamente isso).

## Armadilhas comuns

- **`Mkdir` num diretório que já existe**: devolve erro. Se "garantir que existe" é o objetivo, use `MkdirAll` (que é idempotente) — ou ignore o erro de "já existe".
- **`WalkDir` com erro no callback**: retornar erro encerra a caminhada. Se um arquivo ilegível deve ser ignorado, trate dentro do callback e devolva `nil`.
- **Mudar de diretório com `Chdir`**: afeta o processo inteiro (e qualquer goroutine concorrente). Prefira caminhos absolutos a `Chdir` quando possível.
- **Esquecer de limpar**: árvores criadas em teste/cache acumulam. `RemoveAll` no `defer`.
- **Caminho com espaço/acento**: `Mkdir`/`ReadDir` lidam bem — o problema é só se você montar path na mão (página [Caminhos](file-paths)).

## Pratique

1. **Reproduza**: rode `directories.go` e explique a ordem da saída do `WalkDir` (pais antes de filhos).
2. **Modifique**: mude o `visit` para só imprimir **arquivos** (ignorar `IsDir`) e para contar o total de arquivos.
3. **Aplique**: escreva `func listarPorExt(root, ext string) ([]string, error)` que caminha com `WalkDir` e devolve os caminhos com aquela extensão.
