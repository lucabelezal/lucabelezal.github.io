<GoExampleRow docs={"To count how many _runes_ are in a string, we can use the `utf8` package. Note that the run-time of `RuneCountInString` depends on the size of the string, because it has to decode each UTF-8 rune sequentially. Some Thai characters are represented by UTF-8 code points that can span multiple bytes, so the result of this count may be surprising."} language="go" code={"    fmt.Println(\"Rune count:\", utf8.RuneCountInString(s))"} />

<GoExampleRow docs={"A `range` loop handles strings specially and decodes each `rune` along with its offset in the string."} language="go" code={"    for idx, runeValue := range s {\n        fmt.Printf(\"%#U starts at %d\\n\", runeValue, idx)\n    }"} />
