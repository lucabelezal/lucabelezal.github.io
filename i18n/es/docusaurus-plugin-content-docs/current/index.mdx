# Go by Example

Go es un lenguaje de código abierto diseñado para software escalable y confiable. Consulta la [documentación oficial](https://go.dev/doc/) para obtener más información.

**Go by Example** es una introducción práctica a Go con programas anotados. Empieza por [Hello World](/go/hello-world) o explora la lista siguiente.

> Salvo que se indique lo contrario, los ejemplos asumen la última versión principal de Go. Actualiza si algo no funciona.
