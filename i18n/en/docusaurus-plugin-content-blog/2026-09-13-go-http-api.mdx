## 1. Context

Frameworks solve what the stdlib has solved since 1.22: routing by method and pattern, serving with timeouts, draining shutdown. What frameworks still deliver — validation, DI, docs — gets evaluated later, with measured pain. Start stdlib: fewer layers to debug, break-free upgrades, unsurprising binaries.

![Diagram: request crosses middleware, handler, JSON back](/img/diagramas/go-http-cadeia.svg)

## 2. The problem

APIs without request_ids: three requests fail together and logs can't tell which is which. Without timeouts: slow handlers hold connections forever (free Slowloris). Without Content-Type: clients guess bodies. Without shutdown: deploys kill mid-flight requests. Each has taken down real production — none needs a framework to fix.

## 3. Mental model

**Middleware is a typed onion.** `func mw(log, next) http.Handler`: each layer takes the request, does its part (ids, timers, auth), and calls inward. Order matters: request_id first (everything below logs with it), recovery outside everything.

**Handlers return, never decide infra.** Handlers parse, call services, write JSON + status. Timeouts come from `ctx`; shutdown from `main`; logs from middleware. Fat handlers with `log.Fatal` inside are the classic bug.

**Contract before code.** Method + path + status + body: `GET /health → 200 {"status":"ok"}`, `POST /double {"n":21} → 200 {"result":42}`, invalid JSON → 400 text. Written contracts become tests (curl today, `httptest` tomorrow).

**Rule of thumb.** Stdlib until it genuinely hurts; thin ordered middleware; every handler with `ctx`, every server with timeouts + shutdown (the concurrency post's real `main`).

## 4. Implementation

```go title="main.go" showLineNumbers
func mw(log *slog.Logger, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		id := fmt.Sprintf("req-%d", time.Now().UnixNano()%100000)
		ctx := context.WithValue(r.Context(), reqKey, id)
		l := log.With(slog.String("request_id", id))
		start := time.Now()
		next.ServeHTTP(w, r.WithContext(ctx))
		l.Info("done", slog.String("method", r.Method), slog.String("path", r.URL.Path), slog.Duration("ms", time.Since(start)))
	})
}

mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(map[string]string{"status": "ok"})
})
mux.HandleFunc("POST /double", func(w http.ResponseWriter, r *http.Request) {
	var in struct{ N int `json:"n"` }
	if err := json.NewDecoder(r.Body).Decode(&in); err != nil {
		http.Error(w, "json inválido", http.StatusBadRequest)
		return
	}
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(map[string]int{"result": in.N * 2})
})
```

And in server logs, each request with its identity:

```bash title="Terminal"
{"level":"INFO","msg":"done","request_id":"req-69000","method":"GET","path":"/health",...}
{"level":"INFO","msg":"done","request_id":"req-20000","method":"POST","path":"/double",...}
```

Three `curl`s validate the contract; `request_id` stitches logs to requests. Natural next step: the same cases in `httptest` under CI (the testing post's pattern).

## 5. Failures and trade-offs

**Frameworks on day one.** Chi/Gin/Fiber before the first pain: layers to debug, breaking upgrades, convention lock-in. Adopt when the stdlib proves limits (complex validation, generated OpenAPI, stateful websockets).

**No server timeouts.** Handlers with `ctx` don't save connections without `ReadTimeout`/`WriteTimeout` on `http.Server`: Slowloris holds workers for free. Timeouts on both ends, always.

**`request_id` generated in handlers.** Too late: earlier middlewares already logged without it. Generate at the edge (first middleware), propagate via `ctx`.

**JSON without Content-Type.** Clients trusting bodies break on rewriting proxies. Headers always, before the first `Encode` (after writing, headers lock).
