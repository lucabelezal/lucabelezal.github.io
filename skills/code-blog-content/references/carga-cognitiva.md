# Carga cognitiva

O leitor tem memória de trabalho finita. Um trecho que joga muitos conceitos,
nomes ou números de uma vez perde o leitor. Isso mede o que legibilidade de
superfície (Flesch, Gunning Fog) não vê: **quanto o leitor precisa segurar para
acompanhar**.

## Três cargas (Sweller)

- **Intrínseca** — o tema em si. Não dá para eliminar; dá para escalonar
  (quebrar em subseções, dar andaime, um conceito de cada vez).
- **Estranha** — escrita ruim. **Elimine sem piedade.** Jargão sem explicar,
  pronome sem referente ("É por isso que…" solto), frase monótona, forward
  reference ("veremos depois").
- **Germânica** — o aprendizado que o leitor quer. É boa; sustente (modelo
  mental reutilizável, exemplo depois da definição, repetir o termo-chave).

## Regra da memória de trabalho

Cabem ~4 itens ao mesmo tempo (Cowan, 2001). O leitor segura: o tema do
parágrafo, referências abertas, entidades novas, números a comparar. Se passar
de 4 para entender a próxima frase, o trecho sobrecarregou.

| Sinal | Saudável | Limítrofe | Sobrecarregado |
| --- | --- | --- | --- |
| Entidades novas / 100 palavras | 1–3 | 4–6 | 7+ |
| Números / 100 palavras | 1–3 | 4–5 | 6+ |
| Jargão novo / 100 palavras | 0–1 | 2–3 | 4+ |
| Forward reference / seção | 0 | 1 | 2+ |
| Orações subordinadas / frase (média) | < 1,5 | 1,5–2,5 | > 2,5 |

Duas linhas "sobrecarregado" → quebre antes de publicar.

## Como corrigir

1. **Dividir** o H2 em dois.
2. **Definir inline** o jargão na 1ª aparição.
3. **Reordenar** — entregue o contexto agora, não "depois".
4. **Visual** — tabela, comparação, diagrama reduz carga textual.
5. **Callout** de refresher ("Lembre: X = …") quando o termo já apareceu.
6. **Cortar número** — arredonde, agrupe ou tire. Ninguém guarda
   "23,4%, 87,1%, 41,9%" no mesmo parágrafo.

## Quando pular

Pular em posts < 1.000 palavras e conteúdo de notícia.

Rodar em: guias longos, tutoriais técnicos, posts de dados com vários achados,
comparações longas.

## Checklist

- [ ] Nenhum H2 com 2+ linhas sobrecarregadas
- [ ] Jargão definido na 1ª vez
- [ ] Sem "veremos depois" no meio da explicação
- [ ] Números agrupados/arredondados quando muitos
- [ ] Conceito novo ligado a algo que o leitor já sabe
